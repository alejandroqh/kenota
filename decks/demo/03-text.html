Text styles

Standard tags map to DOS colors: bold is bright, emphasis is yellow, mark is a highlight bar, code is green and Ctrl+C look like keys.

Any element can set its color and background with CSS, using the 16 EGA color names (lightcyan, brown …) or any CSS color, which snaps to the nearest one.

Text can be centered…

…or pushed to the right.
